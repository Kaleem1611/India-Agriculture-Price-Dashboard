# India Agriculture Price Dashboard

## Project Overview
The India Agriculture Price Dashboard is an interactive Excel dashboard developed to analyze agricultural commodity prices across Indian markets and states.

The dashboard helps users compare average prices, identify expensive and affordable markets, and understand price trends across different dates and commodities.

## Dashboard Preview

![India Agriculture Price Dashboard](dashboard-preview.png)

## Tools Used
- Microsoft Excel
- Excel Charts and Data Visualization
- Interactive Filters and Slicers
- KPI Cards
- Market and State-Wise Analysis

## Key Features
- Average price analysis for Onion, Potato, Rice, Tomato, and Wheat
- Year-wise, month-wise, and commodity-wise filtering
- Daily market average price trend
- State-wise average price visualization
- Grading-wise average price comparison
- Top 10 expensive markets
- Top 10 cheapest markets

## Business Objectives
- Compare agricultural commodity prices across markets.
- Identify markets with relatively high and low prices.
- Track price trends over time.
- Present data through an interactive dashboard for easier decision-making.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Enable editing if prompted and allow the workbook to finish loading.
4. Use the available filters to explore prices by year, month, and commodity.
